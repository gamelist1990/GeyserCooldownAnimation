# GeyserCooldownAnimation v1.3.0

Paper bridgeを廃止し、Geyser拡張JARだけで攻撃クールダウンを表示します。
Geyser標準UIと同じ開始時刻・攻撃速度を利用し、サーバーのtick速度と検知までの経過時間を考慮します。
攻撃・空振り・アイテム切替に連動し、標準パック有効・無効の両方に対応します。

Geyserの標準クールダウン設定は有効にしてください。disabledでは本拡張も停止します。
更新時は各Paperから旧GeyserCooldownPaperBridge JARを取り除いてください。

内部APIに依存します。実接続・Velocityサーバー移動・Bedrock実機の見た目は未検証です。
