## GeyserCooldownAnimation v1.2.0

剣・斧・メイスのスイングとクールダウン回復の再生を整理した正式リリースです。
スイング中に腕下げが重なる処理を変更し、振り終わってから元の位置へ戻るようにしました。

### 変更内容

- Blurry's Crossplay Animations 2.0を基準に、武器のスイングと持ち方を統合。
- サーバー通知を時間更新に限定し、腕の描画はBedrock側のcontrollerで制御。
- クールダウンを50ms刻み・1～200tickで指定し、スイング終了時の残り時間で復帰。
- 剣の下げ幅を10、斧・メイスを12に統一。剣・斧はCatmull-Rom、メイスは線形補間。
- 連打時は回復演出を中断してスイングを優先。同じ通知の重複は抑制。
- ツルハシ・hoe・シャベルのカスタム表示を除外。
- ビルドのたびにmcpackのheader/module UUIDを更新し、JAR内のパックと一致させる。
- 生成物と参照整合性の検証、200種類の時間通知と状態遷移の検証をビルドへ追加。

### 更新方法

1. Geyserのextensionsにある旧拡張JARを、GeyserCooldownAnimation-1.2.0.jarへ差し替えます。
2. 各Paperサーバーのpluginsにある連携JARを、GeyserCooldownPaperBridge-1.2.0.jarへ差し替えます。
3. サーバーを再起動し、Bedrockクライアントで再接続してパックを取得します。

単体mcpackの追加配置は不要です。Blurryのパックを同時適用するとplayer/controllerが競合するため、この専用パック単体で使用してください。
パックUUIDが変わるため、クライアント側に残る旧パックは必要に応じて削除してください。

### 配布物

- GeyserCooldownAnimation-1.2.0.jar：Geyser拡張（専用パック同梱）
- GeyserCooldownPaperBridge-1.2.0.jar：Paper連携
- GeyserCooldownAnimation-pack-1.2.0.mcpack：単体リソースパック
- GeyserCooldownAnimation-1.2.0.zip：JAR・パック・導入資料一式
- SHA256SUMS.txt：配布ファイルのSHA-256

### 確認範囲

クリーンビルド、Javaテスト、200種類の時間通知、controllerの遷移条件・下げ幅・補間、パックとJARの一致を検証しています。
自動テストはBedrockの実描画を再現するものではありません。すべての端末・FOV・サーバー構成での見た目の一致は保証しません。
