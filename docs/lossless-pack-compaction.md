# 品質を維持するパック軽量化候補

確認済みの安定リリースはGCA 1.3.14／Glowing 0.2.12です。この版を描画品質の比較基準にしています。以下の検証を経て、GCA 1.3.15／Glowing 0.2.13の正式なビルド工程に組み込みました。

| パック | 圧縮前の配布サイズ | 軽量化候補 | 削減率 | 展開前→後 |
| --- | ---: | ---: | ---: | ---: |
| GCA（本番配信側） | 775,308 bytes | 584,634 bytes | 24.6% | 26,377,344 → 8,947,958 bytes |
| Glowing単独 | 1,395,132 bytes | 998,638 bytes | 28.4% | 26,809,747 → 9,238,742 bytes |

## 方法と検証

- JSONの空白・コメントだけを除去します。数値の表記、Molang文字列、配列の順番、モデルの骨・面を保持します。Decimalで数値を比較し、構造が一致することを検証します。
- ZIPは標準のDEFLATE圧縮を使用します。
- アイコンはPNGの可逆再圧縮を行います。全画素の透明度が255の場合だけ余分な透明度チャンネルを除去します。RGBAとして比較した全画素は同一です。
- PNGのガンマ・sRGB・プロファイル・テキスト等の元のメタデータを保持します。
- アーカイブを読み戻し、ファイル一覧・CRC・内容の一致を確認します。
- これはダウンロード容量と展開時の文字データ量の削減です。モデルの面数は同じなので、描画負荷を削減したとは評価していません。

## 再現

Python 3とPillowが必要です。元のパックやソースファイルは書き換えません。

```bash
python3 scripts/compact_resource_pack.py input.mcpack output-compact-preview.mcpack
```

出力に`.report.json`を付けた検証結果とSHA-256も保存します。入力のmanifest UUIDを保持するプレビューです。正式な次版として配信する際は、新バージョン・新UUIDのビルドから最適化してください。
